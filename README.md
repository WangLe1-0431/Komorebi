# こもれびの種 / Komorebi

2100年の未来製品「こもれびの種」を紹介する、ビルド不要の日本語サイトです。

## 起動

```sh
python3 -m http.server 8765
```

ブラウザーで `http://localhost:8765` を開きます。`index.html`、`styles.css`、`app.js` と `assets/` をそのまま静的ホスティングに配置できます。

## 発表と体験

- ヘッダーの「発表モード」で7章の表示に切り替えます。
- 右・左方向キー、PageDown・PageUp、画面下のボタンで章を移動します。Home・Endで最初・最後へ。Escで通常表示へ戻ります。
- 風景選択、明るさ、音量の調整は、発表モードでも操作できます。スライダー操作の方向キーは章を切り替えません。
- 音はWeb Audioで合成する体験用の環境音です。「音を聴く」を押すまで再生しません。画面を離れると停止します。
- 「故郷の空」ではJPEG・PNG・WebPを選べます（10 MB以下）。一時的なローカル表示のみで、外部へ送信しません。

## 構成

- `index.html`: 商品、使用場面、開発計画と応援プラン
- `styles.css`: 共通の文字サイズ、レスポンシブレイアウト、発表表示
- `app.js`: 自然体験、ローカル写真、キーボード操作、応援確認

応援フローはブラウザー内のUIです。決済サービスへの接続、実際の注文保存や課金処理は含みません。金額・日程・仕様は2100年の製品構想に基づきます。
